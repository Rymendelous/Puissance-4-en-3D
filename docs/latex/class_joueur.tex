\doxysubsection{Description détaillée}
Classe abstraite représentant un joueur. 

Cette classe contient les informations communes à tous les joueurs, comme le nom et la couleur du pion. Elle impose aussi la méthode \doxylink{class_joueur_adce372ce3fe11f9aaa4646ff76e3b917}{choisir\+Coup()}, qui sera redéfinie par les classes filles.
