\doxysubsection{Description détaillée}
Intelligence artificielle utilisant l\textquotesingle{}algorithme Min\+Max. 

Cette IA évalue les coups possibles sur le plateau afin de choisir le coup ayant le meilleur score. Elle utilise aussi l\textquotesingle{}élagage alpha-\/bêta pour limiter le nombre de situations à explorer.
