Gère le déroulement d\textquotesingle{}une partie de Puissance 4.

\begin{DoxyItemize}
\item la gestion des joueurs
\item le suivi du plateau de jeu
\item l’alternance des tours
\item la détection de fin de partie 
\end{DoxyItemize}
